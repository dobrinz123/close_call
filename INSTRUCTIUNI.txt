📋 CUM SĂ FOLOSEȘTI (SUPER SIMPLU):

1. ✅ Dublu-click pe fișierul:  Browser_Blocker.vbs

2. ✅ Aprobă cererea de Administrator (UAC prompt)

3. ✅ O fereastră se deschide cu 3 butoane mari:

   🚫 BLOCK BROWSERS      - Blochează Chrome, Edge, Firefox, Brave
   ✅ UNBLOCK BROWSERS    - Deblochează toate browserele
   👁 DRY RUN             - Testează fără a face modificări

4. ✅ Apasă pe ce vrei!


═══════════════════════════════════════════════════════════════════════

📌 CE FACE PROGRAMUL:

- Blochează accesul la internet al browserelor folosind Windows Firewall
- Browserele pot rula, dar NU au acces la internet
- Când închizi programul, totul revine la normal automat
- Este sigur - nu modifică setări permanente


═══════════════════════════════════════════════════════════════════════

⚠️ IMPORTANT:

✓ Funcționează doar pe Windows 10/11
✓ Trebuie să ai Python instalat (3.6 sau mai nou)
✓ Trebuie să aprobi cererea de Administrator (UAC)
