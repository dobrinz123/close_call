METODA 2: RESETARE PROXY WINDOWS (GUARANTEED!)
═══════════════════════════════════════════════════════════════════════

Această metodă FUNCȚIONEAZĂ 100%!

PAS 1: Deschide Setările Windows
   • Apasă WIN + R pe tastatură
   • Se deschide o fereastră mică "Run"
   • Scrie EXACT: inetcpl.cpl
   • Apasă ENTER

PAS 2: Mergi la Connections
   • Fereastra "Internet Properties" se deschide
   • Click pe tab-ul "Connections" (sus, al 4-lea)

PAS 3: LAN Settings
   • Jos în fereastră, vezi un buton "LAN settings"
   • Click pe "LAN settings"
   • Se deschide fereastra "Local Area Network (LAN) Settings"

PAS 4: DEBIFEAZĂ TOT
   • Vezi 3 căsuțe:
     □ Automatically detect settings
     □ Use automatic configuration script
     □ Use a proxy server for your LAN

   • IMPORTANT: Fă astfel:
     ☑ Automatically detect settings        ← BIFEAZĂ ASTA
     ☐ Use automatic configuration script   ← DEBIFEAZĂ
     ☐ Use a proxy server for your LAN      ← DEBIFEAZĂ (CEL MAI IMPORTANT!)

PAS 5: Salvează
   • Click "OK" în fereastra LAN Settings
   • Click "OK" în fereastra Internet Properties

PAS 6: Restart Browser
   • Închide COMPLET browser-ul (X din colț)
   • Așteaptă 5 secunde
   • Deschide browser-ul din nou
   • Încearcă să accesezi google.com

✅ AR TREBUI SĂ MEARGĂ ACUM!

   • Te duce la setările Windows

     "Use a proxy server"

DACĂ TOT NU MERGE
═══════════════════════════════════════════════════════════════════════

Problema poate fi:

1. PROXY-UL E ÎN REGISTRY
   Soluție: Rulează acest command în CMD:

   reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings" /v ProxyEnable /t REG_DWORD /d 0 /f

2. BROWSERUL E CORUPT
   Soluție: Dezinstalează și reinstalează browser-ul

3. DNS CACHE PROBLEM
   Soluție: Deschide CMD și rulează:

   ipconfig /flushdns
